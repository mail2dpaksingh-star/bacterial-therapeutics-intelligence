# Bacterial Therapeutics Intelligence v1.4 — Professional UI

This release updates the user interface while preserving the Python backend and the v1.3 research workflows.

## Launch
1. Extract the ZIP.
2. Open the `bti_multi_agent` folder.
3. Double-click `START_BTI_WINDOWS.bat`.
4. Open `http://127.0.0.1:8000`.

## What's new
- Refined responsive scientific dashboard and brand system (no NEXUS branding).
- Improved research overview, action buttons, status metrics, and workspace dropdown.
- Contextual workspace descriptions, improved forms, focus states, and mobile layout.
- All original backend endpoints and scientific views retained.

## Notes
The professional UI does not increase the validation status of scientific content. Automated evidence links are discovery aids, not biological causality proof. For public deployment, configure appropriate server-side authentication, HTTPS, rate limiting, and access governance.
