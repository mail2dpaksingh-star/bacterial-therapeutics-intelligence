BACTERIAL THERAPEUTICS INTELLIGENCE v1.5.1

1. Extract the ZIP.
2. Open bti_multi_agent folder.
3. Double-click OPEN_DASHBOARD_WINDOWS.bat.
4. Open http://127.0.0.1:8015 if the browser does not open.
5. The Unified Discovery Dashboard is the default page, above the other workspaces.

This version uses port 8015 to avoid conflicting with an older server on port 8000.
If the page still says v1.4 or v1.3, you opened the wrong server.
A local Python backend must be running for the interactive pathway map.
